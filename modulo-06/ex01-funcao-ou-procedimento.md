# Exercício 1 — Função ou procedimento?

| Item              | Classificação    | Justificativa                                                                                                 |
| ----------------- | ---------------- | ------------------------------------------------------------------------------------------------------------- |
| **Str()**         | **Função**       | É uma função porque converte um número em uma string e retorna esse novo valor ao programa.                   |
| **QOut()**        | **Procedimento** | É um procedimento porque sua finalidade é apenas exibir uma mensagem na tela, sem retornar um valor.          |
| **Date()**        | **Função**       | É uma função porque retorna a data atual do sistema para ser utilizada pelo programa.                         |
| **Len()**         | **Função**       | É uma função porque retorna a quantidade de caracteres de uma string ou o número de elementos de um array.    |
| **Upper()**       | **Função**       | É uma função porque recebe uma string e retorna uma nova versão com todos os caracteres em letras maiúsculas. |
| **ClearScreen()** | **Procedimento** | É um procedimento porque apenas executa a ação de limpar a tela, sem produzir um valor de retorno.            |

## Conclusão

A principal diferença entre uma função e um procedimento é que a **função sempre retorna um valor**, que pode ser utilizado em expressões, cálculos ou atribuições. Já o **procedimento apenas executa uma ação específica**, sem retornar um resultado para o programa.
