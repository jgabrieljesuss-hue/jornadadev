# Exercício 4 — Campo customizado na SA1

## a. Passo a passo no Configurador

1. Abrir o módulo **Configurador (SIGACFG)**.
2. Acessar o dicionário de dados da tabela **SA1**.
3. Criar um novo campo chamado **A1_XAPELID**.
4. Definir o tipo, tamanho e título do campo.
5. Salvar as alterações no dicionário de dados.

## b. Verificação no SmartClient

1. Atualizar o dicionário de dados, conforme realizado em aula.
2. Abrir o cadastro de clientes no **SmartClient**.
3. Acessar a tela de cadastro da tabela **SA1**.
4. Confirmar que o campo **A1_XAPELID** aparece disponível para preenchimento, sem a necessidade de criar nenhuma rotina em código.
