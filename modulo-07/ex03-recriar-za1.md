# Passo a passo — Recriando a tabela ZA1

1. Abrir o módulo **Configurador (SIGACFG)** no Protheus.

2. Criar a tabela **ZA1** no dicionário de dados.

3. Cadastrar os campos da tabela:
   - ZA1_FILIAL
   - ZA1_NOME
   - ZA1_RACA
   - ZA1_DTNASC

4. Salvar a estrutura da tabela.

5. Executar a rotina apresentada em aula para que o framework reconheça a nova tabela.

6. Abrir o **MPSDU** e verificar se a tabela **ZA1** e seus campos foram criados corretamente.
