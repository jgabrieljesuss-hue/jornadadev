# Exercício 1 — Conceitos fundamentais

## a. Qual é a função do AppServer?

O AppServer é responsável por executar as rotinas do Protheus. Ele faz a comunicação entre os usuários e o banco de dados, processando as solicitações do sistema e retornando as informações para quem está utilizando.

## b. O que é o RPO?

O RPO é o repositório onde ficam armazenados os programas compilados do Protheus. É a partir dele que o AppServer executa as rotinas e funcionalidades do sistema.

## c. Para que serve o Configurador (SIGACFG)?

O Configurador (SIGACFG) é o módulo utilizado para administrar e configurar o Protheus. Nele é possível cadastrar usuários, definir permissões, criar e alterar tabelas, campos e outros parâmetros do sistema.

## d. Qual a diferença entre campo Real e campo Virtual no SX3?

Um campo Real é armazenado fisicamente no banco de dados, gravando informações de forma permanente. Já um campo Virtual não é gravado no banco; seu valor é calculado ou obtido durante a execução do sistema, apenas quando necessário.
